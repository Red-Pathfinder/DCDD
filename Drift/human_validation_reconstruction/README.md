# Human Validation Reconstruction

This directory contains a complete, statistically defensible human validation pipeline designed to recompute the inter-rater reliability (Cohen's $\kappa$) statistics for Table 2 of the manuscript.

## Methodology Changes
The original repository validation pipeline exhibited a selective sampling bias, as it only presented images to the human validator when the Vision Language Model (VLM) generated an "ambiguous" label. This made it mathematically impossible to compute a dataset-wide Cohen's $\kappa$.

This reconstructed pipeline fixes the methodology by:
1. **Blind Annotation**: The human validator is completely blind to the VLM's predictions.
2. **Stratified Random Sampling**: A sample of 200 images is randomly selected across all disability conditions and models, without prioritizing ambiguous predictions.
3. **Unified Attributes**: Only the six final attributes evaluated in the paper are annotated.

## Files & Workflow
- `dataset_summary.md`: Identifies the final repository CSVs and image folders used for this evaluation.
- `01_generate_sample.py`: Generates the stratified random sample. (Outputs `sample_manifest.csv` and `sampling_report.md`).
- `02_annotate.py`: An interactive, CLI-based blind annotation tool. Run this script to manually label the images. Progress is saved instantly.
- `human_annotations.csv`: The output file generated by the annotation tool. 
- `03_compute_kappa.py`: The evaluation script. Run this *after* annotation is complete to compute Cohen's $\kappa$ and generate the LaTeX table and Markdown summary.
- `04_verify.py`: A verification script to ensure sample integrity and annotation completeness. (Outputs `verification_report.md`).

## How to use
1. The sample has already been generated (`sample_manifest.csv`).
2. Run `python annotate.py` in your terminal to begin the manual annotation process.
3. Once all annotations are complete, run `python compute_kappa.py` to generate `table2_recomputed.tex`.
